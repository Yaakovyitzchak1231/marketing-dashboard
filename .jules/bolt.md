## 2024-10-10 - Avoiding O(n log n) sorts and intermediate array chaining for single values
**Learning:** Found multiple instances where values like the earliest date were being found using a pattern of `array.map(transform).filter(isValid).sort()[0]`. This has O(n log n) time complexity from the sort, and also allocates intermediate arrays from `.map` and `.filter` that pressure the garbage collector (especially in API load paths). Similar issues exist with arrays being aggregated into Sets like `[...new Set(array.map().filter())]`.
**Action:** When finding a minimum/maximum, or reducing down to a set of unique values, iterate over the source array once with a simple `for...of` loop or standard `for` loop. This transforms time complexity to O(n) and removes all intermediate array allocations.
